# Xero Wallpapers Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild Xero Wallpapers as a PyQt6 + QML/Kirigami app in the #22 "Immersive" layout, with metadata, crop/upscale, coverflow, sort/filter, custom sources, SVWR-gated live wallpapers, first-run and About screens.

**Architecture:**
- A Python package `xero_wallpapers/` holds all logic: config, sources, networking, downloads, wallpaper setting, SVWR, upscaling, colours. Each part is plain Python, unit-tested without Qt.
- A thin Qt layer (`xero_wallpapers/ui/`) exposes it to QML through `QAbstractListModel`s and `QObject` controllers with signals.
- Blocking work runs on a shared `ThreadPoolExecutor` or `QProcess`, never on the GUI thread.
- QML files in `xero_wallpapers/qml/` draw the UI with Kirigami, using `Kirigami.Theme` colours only.

**Tech Stack:** Python 3.14, PyQt6 6.12, Qt Quick + Kirigami 6.31, QtMultimedia, requests, BeautifulSoup4, Pillow, pytest + pytest-qt.

**Spec:** `docs/superpowers/specs/2026-11-07-redesign-design.md` (read it first; mockup reference `docs/designs/src/engine.html?d=22` and `docs/designs/gifs/22-immersive-frost*.gif`).

## Review Focus

1. **A source's HTML changes or a site is offline:** the grid shows an inline "Couldn't load <source>: <reason>" with Retry, and the app keeps working. Owner: Task 3, `test_fourk_parse_garbage_returns_empty`, plus Task 6 `test_browse_error_sets_error_text`.
2. **The user switches source or page quickly:** results from the earlier request must not overwrite the newer one. Owner: Task 6, `test_stale_results_dropped`.
3. **Download folder missing or not writable:** create it if missing. If it can't be written, show an error and leave no `.part` file behind. Owner: Task 4, `test_download_unwritable_dir_cleans_part`.
4. **SVWR install fails (download verification, kpackagetool6 or package manager error, or the pkexec prompt is cancelled):** the card shows the failure and the last log lines, and the toggle stays locked. Owner: Task 8, `test_install_failure_keeps_locked`.
5. **Corrupt or old-format config.json:** load defaults, migrate old keys, and never crash. Owner: Task 1, `test_corrupt_config_falls_back` and `test_migrates_v1_keys`.

### Task 8: Settings dialog, SVWR detect/install/update, live toggle, update pill

**Files:** Create `svwr.py`, `tests/test_svwr.py`, `qml/SettingsDialog.qml`, `SourcesPage.qml`, `DownloadsPage.qml`, `LivePage.qml`, `UpdatePill.qml`. Modify `ui/controllers.py` (SettingsController, SvwrController).

**Interfaces:**
- `svwr.ID`, `svwr.REPO`, `svwr.CHECKOUT = DATA_DIR / "svwr"`.
- `installed_version() -> str | None`: reads `KPlugin.Version` from `/usr/share/plasma/wallpapers/ID/metadata.json`, then `~/.local/share/plasma/wallpapers/ID/metadata.json`.
- `parse_version(s: str) -> tuple[int, ...]` (strips a leading `v`); `is_newer(latest: str, installed: str) -> bool`.
- `latest_release() -> str`: GitHub `https://api.github.com/repos/luisbocanegra/plasma-smart-video-wallpaper-reborn/releases/latest` `tag_name`, with fallback `git ls-remote --tags REPO` (highest semver).
- `distro() -> Literal["arch","fedora","opensuse","other"]`: from `/etc/os-release` `ID` and `ID_LIKE`. This is the only distro switch.
- `latest_asset() -> tuple[str, str, str]`: (tag, download_url, sha256) from `releases/latest`. The asset is named `plasma-smart-video-wallpaper-reborn-<tag>.tar.gz` and its `digest` is `sha256:<hex>`.
- `verify(path, sha256) -> None`: raises `SvwrError("Download failed verification")` and deletes the file on a mismatch.
- `missing_runtime_deps() -> list[str]`: Arch only, `qt6-multimedia` and `qt6-multimedia-ffmpeg` via `pacman -Q` (other distros return []).
- `install_steps(update: bool) -> list[Step]`, where `Step` is either `("download", url, sha256)` or `("run", argv)`:
  - arch/other: `download`, then `kpackagetool6 -t Plasma/Wallpaper -i <archive>` (`-u` for update). Prepended `pkexec pacman -S --needed --noconfirm <missing>` when runtime deps are missing on Arch.
  - fedora: `pkexec dnf install -y plasma-smart-video-wallpaper-reborn` (update: `pkexec dnf upgrade -y plasma-smart-video-wallpaper-reborn`).
  - opensuse: `pkexec zypper --non-interactive install plasma-smart-video-wallpaper-reborn`, after the repo is added via the README's OBS instructions, which the builder confirms. The UI asks before adding the repo.
- `package_latest() -> str | None` for the fedora/opensuse update check (`dnf repoquery --latest-limit 1 --qf %{version}` / `zypper info`). For arch/other, use the `latest_asset()` tag.
- `SvwrController(QObject)`:
  - Properties: `installed: bool`, `version`, `latest`, `updateAvailable: bool`, `running: bool`, `stage: str`, `log: str` (last 200 lines), `error: str`.
  - Slots: `install()`, `update()`, `checkForUpdates(force=False)` (respects `last_update_check` with a 24h gate, caching `svwr_latest`), `copyLog()`.
  - Runs `run` steps with `QProcess` and `download` steps on `net.EXECUTOR` (verify before the next step runs).
  - After success: re-detect, then try `qdbus6 org.kde.plasmashell /PlasmaShell org.kde.PlasmaShell.refreshCurrentShell` (log failures only).
